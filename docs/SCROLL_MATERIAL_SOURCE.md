# 卷轴材料数据来源

本轮材料元素值来自用户提供的 `新-物品-元素含量对照表.xlsx` 第一张工作表，
实际表名为 `物品-元素含量表`，范围 `A2:I127`，共 126 行材料。
文件 SHA-256：
`760abdd87a4e862e3a553e90c571c3201412a05cf2181b647d4486c633a6d9b5`。

源列顺序为物品、金、木、雷、水、土、暗、光、火。导入按列名映射元素，
不假设列顺序与 Java 枚举相同。空元素单元格按零处理，不接受负值、
非整数或重复材料名。原工作簿只读打开，未修改。

项目材料键仍采用源表名称。`铜`、`圆石及其制品`、各羊毛名称等均保留
原表标签，不擅自将其拆分成多个 Minecraft 注册表 ID，也不猜测别名。
源表没有给出的旧材料不继续使用旧元素值参加本轮求解。
原有卷轴配方及主材料定义未从第二张工作表替换。

导入工具：`tools/import-scroll-materials.py`。使用带 openpyxl 的 Python
运行，传入原始工作簿路径；追加 `--check` 可只读核对内嵌材料表。
资源中的 `materialSource` 保存来源摘要。原始理论元素向量不因累计 M 改写。

该表与用户给出的衰减公式共同构成本地模型，不是对服务器数据的直接查询。
客户端确认的材料使用记录也不会修改服务器真实累计量。
