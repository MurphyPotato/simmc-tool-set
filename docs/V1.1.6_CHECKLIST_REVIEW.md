## 本轮实现

- `XaeroCapabilityProbe` 从运行时 ClassLoader 读取 class resource，不初始化 Xaero 类。
- `WorldRuntimeState` 选择旧/现代 surface 与 zoom 适配器；surface、navigation、extended zoom 有独立健康位。
- `MinimapRuntimeState` 选择旧设置或 XaeroLib profile shape；shape 读取失败不猜测圆方形。
- `WaypointHealth` 与地图表面/小地图覆盖层隔离，路点写入失败不会关闭其它能力。
- Mixin 插件按能力快照选择 `MixinWorldSurfaceLegacy/Profiled`、`MixinWorldZoomLegacy/Profiled` 和 Minimap PIP Mixin。
- `build.gradle` 保留默认代表组合，并支持 `-Pxaero_world_map_jar=<path>`、`-Pxaero_minimap_jar=<path>` 构建其它代表组合。已用 1.40.4/25.3.5、1.42.0/26.2.0、1.43.0/26.3.0 和 1.45.0/26.4.2 验证源码构建。
- 无 Xaero 时同时剔除地图生产源和地图测试源，避免可选依赖缺失导致测试编译失败。

## 未完成与禁止宣称

- Minimap 25.2.10-12 的 depth-trace 注入尚未实现，因此该家族保持安全停用。
- 31 个外层 JAR 的静态 catalog 结果来自 `XAERO_MINIMAP_1.21.8_ABI_SURVEY.md` 和 `XAERO_WORLD_MAP_1.21.8_ABI_SURVEY.md`；本次尚未把 catalog 作为 Gradle 自动任务。
- 未启动 Minecraft，未取得 World Map 顶部按钮、地图表面、小地图圆/方裁剪、centered enlarged、路点持久化或未知 ABI 的真实截图/日志。
- 因此 v1.1.6 仍是本地实现候选，不能称为“所有 Xaero 版本完整兼容”，不创建标签或线上 Release。
